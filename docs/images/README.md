# Screenshots

This folder holds the images referenced by the [User Guide](../user-guide.md).
The guide links to the filenames below; drop a PNG with the matching name here
and it will render in place. Until then, the links show as broken images.

Suggested capture: run `pulakat.startup`, then grab each shot from the live
Nansen GUI. PNG, cropped to the relevant panel, readable at ~800px wide.

| Filename | What to capture |
| :--- | :--- |
| `gui-overview.png` | The Nansen GUI just after launch, showing the Dataset table populated with records. |
| `table-selector.png` | The control used to switch between the Dataset, Session, Subject, and File tables. |
| `filter-records.png` | A column filter applied to the Subject table, narrowing the list to one identifier. |
| `import-session.png` | The **Import > Session** menu / dialog on the Dataset table. |
| `import-subjects.png` | The **Import > Subjects** flow on the Session table (Files or Manual). |
| `validate-records.png` | The result of **Validate** on the Subject (or File) table, showing the dry-run report. |
