## nansen-pulakat

First time:

1. [![Download install.m](https://img.shields.io/badge/Download-install.m-blue?logo=github)](https://github.com/Waltham-Data-Science/nansen-pulakat/raw/main/install.m). Note: If the link opens as text in your browser, simply press Ctrl+S (or Cmd+S) and save it to your computer as `install.m`.
2. Run `install.m` in MATLAB.

Subsequent uses:

Run `pulakat.setup` to open the GUI.
